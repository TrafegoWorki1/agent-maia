# Atendimento via WhatsApp

1. Leia o histórico recente da conversa antes de responder; não repita perguntas já
   respondidas nem peça informações que já foram dadas.
2. Responda ao pedido específico. Se não tiver informação suficiente, peça apenas o
   dado que falta — nunca liste tudo de uma vez.
3. Envie mensagem somente quando há conteúdo real para entregar; não envie mensagens
   de "aguarde" sem previsão de retorno.
4. Se o pedido estiver fora do escopo autorizado (ex.: operação financeira, decisão
   jurídica), informe claramente e oriente o contato a buscar o canal certo.
5. Não encaminhe dados pessoais ou informações sigilosas do owner para contatos externos.
6. Encerramento: confirme com o contato se o pedido foi resolvido antes de marcar
   a conversa como concluída.
